# Reactgram

O **Reactgram** é uma rede social desenvolvida em **Next.js**, inspirada na interface do Instagram.  
O projeto tem como foco o estudo e aplicação de boas práticas em **front-end moderno**, autenticação segura e integração com **API externa**.

---

## 🚀 Tecnologias Utilizadas

- **Next.js**
- **App Router**
- **Redux** (gerenciamento de estado e autenticação)
- **Cookies HTTP-only** para autenticação segura
- **API externa própria**
- **Proxy de rotas** para verificação e proteção de acesso
- **Tailwind CSS** para estilização
- **shadcn/ui** para rapidez na reutilização de componentes

---

## ✅ Funcionalidades Implementadas

- Autenticação de usuários
- Criação de posts
- Listagem de posts no dashboard
- Página de perfil de usuário logado.
- Edição de perfil de usuário logado.
